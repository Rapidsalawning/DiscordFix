> ### Обнаружение антивирусом
>
> WinDivert может сработать как антивирусная угроза.  
> Это компонент для перехвата и фильтрации сетевого трафика, который требуется zapret.
> Один и тот же инструмент могут применять как полезные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle):**
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства, после чего удаляет их и отправляет в карантин. В названии обнаружения обычно присутствует `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky содержит настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтительно добавить исключение, но если вы не полностью понимаете последствия, лучше отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите конкретного поставщика, а не вариант "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдет `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Rapidsalawning/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не нужен.

4. Распакуйте архив в каталог без кириллических и специальных символов в пути.

5. Запустите подходящий файл.
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск используйте **`service.bat`** -> `Install Service` и выберите нужный вариант.

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию напрямую.

  Такой запуск удобен для проверки вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдете подходящую для своей системы**.

- [**`service.bat`**](./service.bat) содержит установку в автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других программ, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние включения или отключения указано в скобках.
  - **`IPSet Filter`** управляет режимом обхода ресурсов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret открывается, а с ним перестает работать.  
  В скобках отображается один из режимов:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет текущий используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** загружает актуальную версию `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную ищет доступные обновления.
  - **`Run Diagnostics`** проверяет распространенные причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения после внезапного сбоя.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не изменилось

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/522).

### Подходящей стратегии нет
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Запустите текстовый редактор от имени администратора и откройте файл `hosts` в появившейся папке.
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки.
  - Сохраните файл и снова проверьте подключение. При отсутствии результата убедитесь, что hosts действительно был сохранен.

#### Работа этого способа не гарантируется. Если он не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Rapidsalawning/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение конкретного варианта может произойти спустя некоторое время, поэтому ранее рабочая стратегия иногда перестает помогать.
> В репозитории собрано много вариантов обхода. Если готовые настройки не подходят, создайте новую стратегию на основе одной из них и измените ее параметры.
> О параметрах стратегий можно прочитать [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте наличие ошибок.

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов.

- Проверьте другие варианты, в том числе **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- См. [#765](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие нужные данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце подтвердите действие клавишей Y.
- Удалите старый каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/Rapidsalawning/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска. В пути не должно быть пробелов и специальных символов.
- Перебирайте `general`-скрипты и после каждого запуска проверяйте интернет-ресурсы. Если вариант не работает, закройте программу через значок замка на панели задач и запустите следующий.
- Найдя подходящую стратегию, добавьте ее в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включенном zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. В противном случае фильтр может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Получите имя службы командой в командной строке Windows. Откройте `cmd` через Win+R и выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Попробуйте остальные стратегии, особенно если прежняя настройка раньше работала.
- См. также [#251](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить ее.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, временно пользуйтесь ею.
- Если Discord не открывается и в браузере, последовательно проверьте остальные стратегии. YouTube и Discord могут работать на разных настройках.
- См. также [#252](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/252).

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/Rapidsalawning/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Попробуйте следующий общий порядок:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не держите его включенным постоянно. Вместо этого определите все IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если результат отсутствует и после этого, создайте обсуждение в разделе [Discussions](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте обращение [здесь](https://github.com/Rapidsalawning/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены, которые нужно исключить. Например, это требуется, если сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не следует.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, подлежащие исключению.
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`.
